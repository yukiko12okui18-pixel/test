## これは何?

Git / GitHub の基本的な使い方(add → commit → push)を試すために作った
サンプルファイルです。

## 基本コマンドのおさらい

1. `git add <ファイル>` — 変更を「次のコミットに含める」対象にする
2. `git commit -m "メッセージ"` — 今の状態をセーブポイントとして記録する
3. `git push -u origin <ブランチ名>` — 自分の記録を GitHub に反映する

## プルリクエスト(PR)とは

「このブランチの変更を、main ブランチに取り込んでください」という提案のこと。
GitHub の画面上でレビューしたり、承認してからマージ(合体)したりできる。
