# 名刺ひな形

デザイン(レイアウト)は固定のまま、**名前・部署・携帯番号などの「人によって変わるところ」だけを差し替えて**名刺を作るためのひな形です。

## 自分で編集したいとき(いちばん簡単)

`名刺エディター.html` をダブルクリックしてブラウザ(Chrome や Edge)で開くだけで使えます。プログラムもインストールも要りません。

1. 左の欄に氏名・部署・携帯などを入力すると、右の名刺がその場で変わる
2. ロゴ画像はファイルを選ぶだけで入る
3. 「印刷する」で印刷(A4用紙に10枚ならべる/名刺サイズ1枚、を選べる)。「PDFに保存」を選べば PDF にもなる

入力した内容はブラウザに自動保存されるので、次に開いたときもそのまま残っています。

## ファイルの役割

| ファイル | 中身 | 触る頻度 |
|---|---|---|
| `data.json` | 名前・部署・携帯など **変わる情報** | よく書き換える |
| `template.html` | 名刺のデザイン(91mm×55mm) | ほぼ触らない |
| `名刺エディター.html` | 画面で入力して作れる編集用ページ | 自分で作るとき |
| `make_cards.py` | data.json を template.html に流し込むスクリプト | 触らない |

## 使い方

1. `data.json` の `people` の中身を書き換える(人を増やすときは `{ ... }` をコピーして `,` で並べる)
2. 次のコマンドを実行する
   ```
   python3 make_cards.py
   ```
3. `output/` フォルダに `山田花子.html` のようなファイルができるので、ブラウザで開いて印刷(または「PDFに保存」)

## 変えられる項目

**全員共通(company)**:会社名、会社名_英語、郵便番号、住所、代表電話、URL、ロゴ画像(画像ファイルのパス)

**1人ずつ(people)**:氏名、ローマ字、部署、役職、携帯、メール

- 役職・携帯・メール・URL・ロゴ画像は **空欄 `""` にするとその行ごと自動で消えます**
- テンプレートの中では `{{氏名}}` のように `{{ }}` で囲んだところが差し替わります。項目を増やしたいときは、data.json に項目を足して、template.html に `{{その項目名}}` を書けばOKです

スキル(SKILL.md)に次のように書いておくと、Claude に「◯◯さんの名刺作って」と頼むだけで作れます。

```
名刺を作るときは meishi/ フォルダを使う。
1. ユーザーから氏名・ローマ字・部署・役職・携帯・メールを聞く(わからない項目は空欄でよい)
2. meishi/data.json の people をその内容に書き換える(company は変えない)
3. python3 meishi/make_cards.py を実行し、output/ にできたファイルを渡す
```
